# Caesar Fan

多页静态个人站。对外署名 **Caesar Fan**。默认中文，可切英文。

## 页面

| 文件 | 内容 |
| --- | --- |
| `index.html` | 首页 |
| `work.html` | 工作面（配图 + 术语说明） |
| `projects.html` | GitHub 自有项目 |
| `awards.html` | 荣誉 |
| `about.html` | 关于 / 路径 |
| `contact.html` | 联系（仅 GitHub） |

本站**不展示真名、电话，也不使用编造的企业/学校商标图**。

## 本地预览

```bash
python3 -m http.server 8080
```

打开 `http://127.0.0.1:8080`。

文案与项目列表：`assets/i18n.js`。
